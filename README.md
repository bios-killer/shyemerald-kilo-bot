# shyEmeraldKiloBot

Telegram-мост к [Kilo CLI](https://kilo.ai): пишешь сообщение боту в Telegram — оно
уходит в `kilo run --auto` на сервере, готовый ответ возвращается в чат.
Поддерживает непрерывность сессии, смену модели и режима (агента), стоп задачи,
приём фотографий.

## Как это работает

- Длинный опрос (`getUpdates`) принимает сообщения **только из разрешённого чата** (`chat_id`).
- Каждое сообщение ставится в очередь и выполняется одним воркером последовательно.
- Запуск: `kilo run --auto -m <model> --agent <mode> [-c] "<text>"` в рабочей папке `workspace/`.
  Флаг `-c` (продолжение сессии) добавляется для всех сообщений, кроме первого после `/new`.
- Ответ очищается от ANSI-кода и служебных строк Kilo и отправляется в чат (частями до 3900 символов).
- Пока Kilo работает, в чате каждые 4 секунды отправляется `typing`.
- Таймаут задачи — **15 минут**, после чего процесс убивается (вместе с деревом процессов).

## Установка

```bash
git clone https://github.com/bios-killer/shyemerald-kilo-bot.git
cd shyemerald-kilo-bot

# 1. Создай бота у @BotFather, получи токен
# 2. Узнай свой chat_id (например, у @userinfobot)
cp config.json.example config.json
nano config.json   # вставь token и chat_id, chmod 600 config.json

# 3. Убедись, что бинарник kilo доступен в PATH
# 4. Запуск вручную (проверка):
python3 bot.py

# 5. Постоянная работа через systemd:
sudo cp kilo-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now kilo-bot.service
journalctl -u kilo-bot -f        # смотреть логи
```

Зависимости: Python 3 (только стандартная библиотека), установленный `kilo` CLI.

## Команды бота

| Команда | Действие |
|---|---|
| `/start`, `/help` | Справка + текущая модель и режим |
| `/providers` | Список провайдеров моделей |
| `/models [фильтр]` | Список моделей; `/models free` — только `:free`, `/models zai` — по подстроке |
| `/model <id\|номер>` | Смена модели (номер — из последнего `/models`) |
| `/mode` | Список режимов (code, plan, ask, debug, orchestrator) |
| `/mode <name>` | Смена режима/агента |
| `/current` | Текущая модель, режим, статус сессии |
| `/new` | Сброс: следующее сообщение начнёт чистую сессию в режиме `plan` |
| `/stop` | Убить текущую запущенную задачу Kilo |

Всё остальное, что ты пишешь, уходит в Kilo как обычный запрос.

## Хинты

- **Фотографии**: пришли картинку (файлом или фото) — бот скачает её в
  `workspace/pics/img_<timestamp>.<ext>` и попросит Kilo разобрать её инструментом Read.
  Подпись к фото станет частью запроса.
- **Сессия**: по умолчанию сообщения продолжают одну сессию (`-c`). Сброс — `/new`.
  Смена модели/режима применяется к **следующей** сессии — после смены стоит сделать `/new`.
- **Свободные модели** иногда возвращают пустой ответ (заканчивают после tool calls
  без итогового текста). Бот в этом случае подскажет `/new` или более стабильную модель.
- **Очередь**: задачи выполняются строго по одной; пока воркер занят, новые ждут.
- **Состояние** (`state.json`) хранит модель/режим/флаг сессии и переживает перезапуск.
- **Длинные ответы** режутся на части по ~3900 символов (лимит Telegram).
- Права доступа Kilo настраиваются в `workspace/kilo.json` (что можно выполнять без вопроса).

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Код бота |
| `config.json` | **Секрет**: токен бота и chat_id (в git не попадает, chmod 600) |
| `config.json.example` | Шаблон конфига |
| `state.json` | Текущее состояние (модель/режим/сессия), runtime |
| `kilo-bot.service` | Юнит systemd |
| `workspace/` | Рабочая папка Kilo: `kilo.json` (права), `pics/` (скачанные фото) |

## Безопасность

`config.json`, `state.json`, `__pycache__/` и runtime-файлы workspace исключены из
репозитория через `.gitignore`. Никогда не коммить токены.
